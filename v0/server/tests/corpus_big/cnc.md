# Haas VF-2 Operator Quick Card (fictional)

<!-- page: 1 -->
## Spindle warm-up

Run the spindle warm-up program for 10 minutes at 2000 RPM if the machine has been idle more than 4 hours.

<!-- page: 2 -->
## Tool offset

Touch off with the probe: press Offset, select the tool number, then Z Face Measure. Tool length offsets must be within 0.002 inch of the setup sheet.

<!-- page: 3 -->
## Coolant

Mix coolant at 8 percent concentration with a refractometer. Replace the tank every 6 months. Skim tramp oil weekly.

<!-- page: 4 -->
## Alarm 108 servo overload

Alarm 108 means axis servo overload. Reduce feed rate, check for a crashed way cover, and clean the chip pile. Reset with the power-up key.
